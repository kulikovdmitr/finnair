## First task

An airline product team has a list of ten Origin cities and Destination cities for travel,
for which regression testing needs to be performed every week. The product’s
website resembles google/flights website. You need to plan and automate the
testing for this product team. The scope of testing is only to automate the UI testing.
Describe your testing approach. Write test cases such that your scripts take origin
and destination one by one from the list of ten pair of cities, then search for flights
on the website, recursively yet in one single execution. You can leave the travel
dates unchanged on the website.

## Second task

The project you are supporting has test data in the form of Microsoft excel file. The
file has over 5000 rows of test data, each row containing passenger’s first name,
last name, phone number, email ID, etc., which should be used as the input for test
scripts. Describe your approach to design and automate the testing using this test
data. Write scripts to import this data from excel file and use it in your test case.
Write a test case to print the data to the console.
